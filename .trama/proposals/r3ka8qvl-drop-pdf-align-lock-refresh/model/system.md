# OpenNotes

OpenNotes è un'app di note ispirata ad Apple Notes, pensata per chi vuole scrivere e organizzare note personali su desktop (Linux, macOS, Windows) e su mobile (Android, iOS), con un'interfaccia che si adatta alle dimensioni della finestra.

Le note si scrivono in un editor a blocchi con formattazione dal vivo (grassetto, corsivo, sottolineato, titoli, elenchi, checklist, citazioni, tabelle, immagini, disegni) e scorciatoie Markdown. Si organizzano in cartelle e con tag, si possono fissare in alto, duplicare, spostare, mettere nel cestino e ripristinare oppure eliminare definitivamente. Le note riservate si possono bloccare con un PIN principale.

L'app è local-first: tutto funziona senza rete, con un database locale e una copia di ogni nota in Markdown in una cartella "vault" del dispositivo. Al primo avvio vengono create due note di benvenuto. In modo facoltativo l'utente può accedere con Google e sincronizzare le note con il cloud (Supabase), scaricando anche le cartelle e ricevendo in tempo reale le modifiche fatte da altri dispositivi. Le note si possono esportare in Markdown e condividere tramite il sistema operativo. L'interfaccia è in italiano.
