# Organization

Come l'utente organizza e ritrova le note: le cartelle (quelle create dall'utente e la cartella di sistema "Note"), i tag ricavati dal testo delle note, le viste dell'elenco (Tutte le note, una cartella, uno o più tag, Eliminati di recente) con la ricerca testuale, i conteggi per vista e la nota selezionata.
