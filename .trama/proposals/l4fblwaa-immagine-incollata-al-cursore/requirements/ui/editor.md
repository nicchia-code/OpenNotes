# Editor

## note-editor
- Se un'immagine incollata non si può salvare, oppure non viene inserita perché nel frattempo è stata aperta un'altra nota o nessuna, compare in basso un avviso (SnackBar) con il testo «Immagine non incollata», come gli altri avvisi dell'app.
