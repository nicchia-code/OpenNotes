# Notes

Ciclo di vita delle singole note di OpenNotes: creazione (anche da filtro per tag), note di benvenuto al primo avvio, duplicazione, fissaggio in alto, segnalazione di nota protetta, spostamento tra cartelle, spostamento nel cestino con annullamento, ripristino ed eliminazione definitiva, singola o svuotando il cestino. Ogni salvataggio locale scrive la nota nel database del dispositivo e nell'archivio Markdown (vault) e accoda il cambiamento per la sincronizzazione con il cloud; le versioni ricevute dal cloud sostituiscono quella locale se non è più recente.
