# Export

Copie delle note fuori dall'app. Ogni nota salvata sul dispositivo ha anche una copia in un file Markdown dentro il vault locale, una cartella creata all'avvio dell'app nei documenti dell'applicazione, con accanto la cartella degli allegati. Dal menu di una nota (non nel cestino) l'utente può condividere il testo della nota convertito in Markdown con il foglio di condivisione del sistema, oppure salvarlo come file Markdown in una posizione scelta. L'app sa anche impaginare una nota in PDF e aprire la finestra di stampa del sistema, ma nessuna schermata offre questa azione.
