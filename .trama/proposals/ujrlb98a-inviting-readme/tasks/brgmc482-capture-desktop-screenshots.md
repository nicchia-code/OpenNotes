# Capture desktop screenshots with sample notes

Produrre le due catture della finestra desktop per il README, in tema chiaro e in tema scuro, salvate come PNG in `docs/screenshots/`.

- Avviare l'app con dati separati da quelli del developer: né il suo database, né il suo vault, né il suo account.
- Preparare note di esempio inventate, senza dati personali, con almeno una checklist, una tabella, dei tag e più di una cartella.
- La finestra mostra barra laterale, elenco note ed editor con una nota di esempio aperta.
