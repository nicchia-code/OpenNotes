# Delete command in the desktop trash view

Nella vista Cestino della barra desktop, il comando di eliminazione sulla nota selezionata deve riportarla nel cestino, aggiornando la data di eliminazione e la data di modifica e lasciando invariati cartella, fissaggio e protezione. Oggi la barra desktop non offre questo comando nella vista Cestino.
