# Fix code to match the Requirements: Double-click on the top bar does not maximize the window

Su Linux, macOS e Windows, un doppio clic sulla barra superiore dell'app deve ingrandire la finestra se è normale, oppure riportarla alla dimensione normale se è ingrandita. Oggi la barra sposta soltanto la finestra: il doppio clic non ha alcun effetto. Il pulsante verde su Linux e Windows deve continuare a funzionare come ora.
