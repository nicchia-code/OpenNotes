# Fix code to match the Requirements: Sign-out button sits above the sync status in the cloud settings window

The cloud settings window shows the signed-in account with its sign-out button on the same line as the email. The Requirement places the sync status below the email and before both the sync-now and the sign-out buttons. Move the sign-out button below the sync status block, so that the status, the last synced time, the pending changes, the retry line and the set-aside changes all come before the sign-out button.
