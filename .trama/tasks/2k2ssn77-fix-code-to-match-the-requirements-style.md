# Fix code to match the Requirements: Style change on several selected lines marks only the caret line

Scegliendo dal menu Aa o dal menu rapido elenco, checklist, numerato, citazione o monospazio con più righe selezionate, ogni riga selezionata riceve il nuovo simbolo e la selezione resta. Oggi, se almeno una riga aveva già un simbolo, il nuovo simbolo va solo sulla riga del cursore, le altre righe restano senza simbolo e la selezione si riduce al cursore.
