# Fix code to match the Requirements: Mobile Aa menu lacks Checklist, Quote and Monospace

Il menu Aa su mobile deve offrire, come quello desktop, gli stili Checklist, Citazione e Monospazio oltre a Titolo, Intestazione, Sottointestazione, Corpo, Elenco puntato e Numerato. Scegliendo una di queste voci, le righe selezionate perdono i simboli esistenti e assumono il simbolo dello stile scelto: cerchio vuoto per la checklist, segno di citazione per la citazione, segno di monospazio per il monospazio.
